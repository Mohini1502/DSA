*Logic of Armstrong Number

Let’s check if 153 is an Armstrong number 👇

Step 1️⃣: Count digits
153 has 3 digits

Step 2️⃣: Take each digit and cube (³) it
→ 1³ = 1
→ 5³ = 125
→ 3³ = 27

Step 3️⃣: Add them up
1 + 125 + 27 = 153

✅ The sum equals the original number → 153 is an Armstrong number
